# assets

`resourceExtensions/` is copied unchanged from BlueMap (`core/src/main/resourceExtensions`, MIT, © Blue) at
upstream commit `84ee993`. BlueMap layers it under every resource pack: default block states for palettes that omit
properties (`data/minecraft/defaultBlockstates.json`), hand-made models for blocks the vanilla client renders in
code (chests, signs, beds, banners, skulls), and version overlays (`mc1_15/` … `mc26_1/`).

Refresh it from upstream when bumping the targeted BlueMap release; don't edit it here.
